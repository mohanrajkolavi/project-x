The four UI glyphs from caro's kit, 24px grid, round caps: `arrow` (links), `chevron` (next), `mail` (newsletter), `down` (story CTA).

These files are single-ink white (#FFFFFF) for `<img>` use on Black. In pages, inline them through `Caro.icons` or `data-ck-icon`, which draw with `currentColor` and follow the text colour in both themes.
