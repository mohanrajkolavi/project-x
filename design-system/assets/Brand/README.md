The two marks of @mohanrajkolavi, drawn for the Black theme.

`planet-avatar-mk.svg`: the "MK" planet, a blue sphere (`planet-hi` → `planet-deep`) with `glow-planet`, in a 1.25px `sig-text` orbit at 45% with one `t1` moon at 140°. "MK" is outlined Montserrat 700, so it renders without the font. Use it as the site avatar, favicon source and author mark; in pages, prefer the live `.ck-planet` component so it follows the theme.

`webb-mark.svg`: the Webb six-spike star in `sig-text` (#2997FF) with a white core, the page-label mark in the header. Ink is fixed; for White use the inline `Caro.webb()` version, which follows `sig-text` and `webb-core`.
